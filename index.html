Industrio

As passion project that I created due to my love of Roblox Islands and factory games, Industrio is a factory and automation game with a player-run economy and robust data management systems to protect the economy.

Game Dashboard

Due to the fact that Industrio has a player-run economy, I needed a way to track movements and see when items are overpopulating to better plan updates to stabilize item counts and retain rarities.

Game Playtester

As a solo developer, shipping large updates weekly with good quality is nearly impossible, so I created a playtest system that utilizes claude, and MCP servers to allow AI to play the game with specific personas and find bugs before a player ever touches the game.

Content Editor

JSON files are generally hard to read; however, Industrio uses JSON for almost all of the data in the game with 100s of files, so I created a local web app to manage JSON and push to the master server.
